# Honest, Leakage-Free Chart+Sequence Deep Learning for NSE Stock Direction

## Setup

1. Create a virtual environment:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
2. Install dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
3. Run smoke tests:
   ```powershell
   pytest tests/
   ```
